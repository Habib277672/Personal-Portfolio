# Personal Portfolio - Habib Ur Rehman

Portfolio moderne en **React + Vite + TypeScript**, avec Swiper, Anime.js et ScrollReveal.

Live demo: https://habib277672.github.io/Personal-Portfolio/

## Scripts

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Stack

- React 19
- Vite 8
- TypeScript
- Swiper (carrousel projets)
- Anime.js (animation hero)
- ScrollReveal (animations au scroll)

Les assets statiques (images, PDF) sont dans `public/assets/`.
